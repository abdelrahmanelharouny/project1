Public endpoints. Only /api/v1/health liveness and readiness checks are reachable without a token. Every other endpoint requires a valid bearer token issued by the authentication service.
Audit trail. Security-relevant actions (logins, token issue and revoke, data changes) are recorded in an append-only audit table, and every query is scoped to the caller’s organization.
Connection hygiene. Database connections are pooled and recycled on a fixed schedule, so long-lived services never hold stale sessions.
