# Provider Contracts

## Protocol

```python
@runtime_checkable
class EnvironmentalDataProvider(Protocol):
    provider_code: str

    def fetch_observations(
        self,
        *,
        area_of_interest: AreaOfInterest,
        variables: list[str],
        start: datetime,   # tz-aware UTC
        end: datetime,
        options: dict | None = None,
    ) -> ProviderFetchResult: ...
```

- `AreaOfInterest` — field_id, GeoJSON geometry (EPSG:4326), area_ha.
- `ProviderFetchResult` — provider_code, **provenance** (provider/product/version, license, attribution, documentation, limitations, retrieval method), observations, warnings, coverage diagnostics, provider_request_id, optional raw reference.
- `CanonicalObservation` — variable_code, value (None ⇒ missing), unit, observed_at/period_start/period_end (UTC-enforced), time_support, spatial_support_type/resolution, quality_status, uncertainty (None = unknown), evidence_class, **is_synthetic**, processing_version, metadata, quality_flags.

## Registry

`app/data_platform/registry/provider_registry.py` — keyed by `provider_code`; unknown codes raise `NOT_FOUND`; `/api/v1/data/providers/health` exposes kind/status/details. Registering a future provider requires no changes to ingestion or passport code.

## Registered providers (Milestone 3)

| provider_code | kind | status | data | notes |
|---|---|---|---|---|
| `synthetic` | synthetic | active | fixtures | deterministic, seeded, always labelled SYNTHETIC |
| `open_meteo` | api | active | **REAL** archive (ERA5-Land / ERA5) | explicit model selection; verified model↔variable matrix (`MODEL_VARIABLES`); UTC basis; null→missing; 10 y chunks; CC BY 4.0 |
| `chirps_import` | raster_import | active* | **REAL** CHIRPS v3 via GeoTIFF upload | upload → field-mean extract; EPSG:4326 enforced; nodata accounting; product kind/status recorded; *degrades without rasterio |
| `soilgrids` | api_wcs | optional | **REAL** SoilGrids 2.0 (ISRIC WCS) | 0-5 cm depth (slice scope); Qmean+Q0.05/Q0.95 → 90% interval; graceful PROVIDER_UNAVAILABLE |
| `farmer_csv` | file_import | active | farmer CSV upload | strict row validation; farmer_reported_record evidence; sha256+row provenance |

Optional provider hooks: `supported_variables()` (advertised via health details, used for UI filtering + route fail-fast) and `validate_request(variables, options)` (no-network fail-fast, e.g. Open-Meteo model fit). Probes: short-timeout, cached, never raise — `open_meteo` probes the archive, `soilgrids` probes DescribeCoverage.

## Contract test suite (must pass for EVERY provider)

Run against synthetic, Open-Meteo (mocked HTTP) and SoilGrids (mocked WCS + GeoTIFF fixtures); the CSV import pipeline has an equivalent contract/integration suite:

1. Implements the protocol (runtime checkable).
2. Returns valid canonical objects (Pydantic re-validation, UTC timestamps, period containment).
3. Includes full provenance (product/version, attribution, limitations).
4. Units match the canonical variable catalog.
5. Preserves native temporal support (daily for synthetic).
6. value=None ⇔ quality_status=missing (no zero-fabrication; uncertainty unknown stays None).
7. Rejects invalid date ranges and unsupported variables with structured errors.
8. Idempotent rerun → identical results.
9. Synthetic rows always labelled (`is_synthetic=true` + attribution).
10. Coverage diagnostics + provider request id present.

## Synthetic provider specifics

- **Determinism**: RNG seed = SHA-256 of {seed, profile, AOI geometry, sorted variables, start, end}. Same request ⇒ identical series; variable order irrelevant.
- **Profiles** (fixture shape constants, NOT agronomic claims): temperate_seasonal, mediterranean_dry_summer, semi_arid, tropical_seasonal, arid_irrigated.
- **Coverage**: 2015-01-01 .. 2024-12-31, ≤ 4 years per request.
- **Gaps**: deterministic injected missing days (flag `SYNTHETIC_GAP`, info) exercising missing-data paths.
- **Labelling**: every row `is_synthetic=true`; metadata carries generator_version/seed/profile/purpose; product attribution: "SYNTHETIC TEST FIXTURE — generated by CropTwist; not real-world data; no agronomic validity."
