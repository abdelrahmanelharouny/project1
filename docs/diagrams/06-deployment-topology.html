Threat model — sandbox reset
The sandbox periodically recycles processes and deletes large untracked directories inside the project (node_modules, venvs) and can reset /home/z/fieldshift-* entirely. Recovery playbook: rsync source from the /tmp recovery copy → recreate pgenv with micromamba at a fresh prefix → initdb + ensure_db → alembic upgrade head → rebuild API venv → restart daemons → re-seed demo workspace. Git history and /tmp survive every reset observed so far.
