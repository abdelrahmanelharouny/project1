Client
Web Browser
Any modern browser · no plug-ins required
Loads the single / route workspace; the interactive field map (maplibre-gl) runs entirely client-side after hydration.
HTTPS — the only externally exposed port
Edge
Edge Gateway — Caddy
reverse proxy · the only externally exposed port
Terminates all external traffic and routes each request to the appropriate internal service. Supports WebSocket upgrade for real-time features; no database or service port is reachable from outside.

Background Job Workers
in-process pool · progress & stage tracking
Long-running operations are recorded as BackgroundJob rows and executed by workers inside the API process — callers receive 202 Accepted with a job id and poll /jobs/background/{id} for progress percentage and current stage, instead of holding the request open.

Data tier
PostgreSQL 16.10 + PostGIS 3.5.0
port 5433 · network access restricted to localhost
  • 81 tables in a single database, croptwist
  • Version-controlled schema migrations (Alembic) with a single merged head
  • Geometry columns via PostGIS; database-level immutability triggers on finalized scenarios
Operations & supervision
Process Supervisor
double-fork daemon launcher
Services are launched detached from the starting shell and log to dedicated files — operation does not depend on an interactive session.
Automated Supervision
health-check cycle · every 10 minutes
Checks PostgreSQL readiness, then API /health/ready, then the web root — and restarts any service found down. Restarts only; rebuilding artifacts is always a deliberate, approved action.
Isolated Runtime Layout
runtime ≠ source tree
Runtime environments (database cluster, Python environment, frontend build) live outside the source tree, so dependency clean-ups cannot damage running services.
