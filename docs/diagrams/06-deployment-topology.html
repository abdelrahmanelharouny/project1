Escalation policy
supervision never rebuilds
If runtime artifacts are missing, supervision reports and stops — rebuilding is an explicit, approved operation.
Environment resilience & recovery
The hosting environment periodically recycles processes and may clear ephemeral directories. The recovery playbook restores the full stack from version control: restore source from the recovery copy → recreate the PostgreSQL environment with the bootstrap tool → initialize and migrate the database → rebuild runtime environments → restart supervised services → re-seed the demonstration workspace. Git history and the recovery copy persist across resets.
